{{ if eq (default "none" .Values.config.auth.mode) "none" -}}
WARNING: authentication is off (config.auth.mode is "none"). Every visitor is
an admin, and can upload, delete and push routes. Before exposing this to
anything, put it behind Authelia and set:

    config:
      auth:
        mode: proxy
        trusted_proxies: [<your pod CIDR>]
{{- end }}

{{ if .Values.postgresql.existingSecret -}}
The library is PostgreSQL, from Secret/{{ .Values.postgresql.existingSecret }}
(key {{ .Values.postgresql.secretKey }}).
{{- else -}}
The library is PostgreSQL, from Secret/{{ .Values.postgresql.cluster }}-app —
the connection string CloudNativePG publishes for cluster
{{ .Values.postgresql.cluster }}. It follows a failover on its own.
{{- end }}

Nothing is kept on disk: routes, sync state, linked head units and Komoot
sign-ins are all rows. The pod has no volume and can be replaced freely.

{{ if not .Values.encryptionKey.existingSecret -}}
Komoot sign-in from the UI is off: no encryption key, and a session would
have to be stored unencrypted. To enable it, put a key in a Secret and set
encryptionKey.existingSecret:

    domestique keygen
{{- end }}
